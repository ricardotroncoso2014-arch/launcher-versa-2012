# Versa Launcher
Launcher para radios Android de auto (Nissan Versa).
Fondo: app/src/main/res/drawable/bg.jpg (reemplaza con tu foto, misma ruta y nombre).
APK: Android Studio > Build > Build APK(s), o sube el proyecto a GitHub y descarga el APK desde Actions.
Pantalla dividida: mantén presionado Maps o Waze (requiere que el radio soporte multiventana).
